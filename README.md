# Sidcup Family Golf ⛳

I completed a project where I created a clone of the Sidcup Family Golf website using HTML and CSS, aimed at enhancing my web development skills through hands-on practice. 

## 🌐 Live Demo
Check out the live website here: [https://abhayy-chauhan.github.io/SidCupFamily-Golf/](https://abhayy-chauhan.github.io/SidCupFamily-Golf/)

## 🚀 About the Project
This project, built with a focus on replicating the design and functionality of the Sidcup Family Golf website, includes several key features that contribute to a comprehensive user experience:

* **Responsive Layout:** The homepage is designed with a clean and elegant layout, featuring a responsive navigation menu that adapts seamlessly to different screen sizes, ensuring accessibility on both desktop and mobile devices.
* **Photo Gallery:** The website includes a visually appealing photo gallery that showcases various golf courses and events, organized using CSS Grid to create a neat and structured presentation.

## 🛠️ Built With
* **HTML5**
* **CSS3** (Flexbox & CSS Grid)
* **JavaScript**
* **Hosted on:** GitHub Pages
